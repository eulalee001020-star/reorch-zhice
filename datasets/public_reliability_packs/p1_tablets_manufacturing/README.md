# P1 Tablets Manufacturing Pack

Source: https://data.mendeley.com/datasets/mm7yr6t7pp/1

CC BY 4.0 anonymized real-world tablet manufacturing planning data. The
canonical layer includes demand work orders, machine capacity, BOM-linked
operations, and setup matrices.

The public source is a lot-sizing/planning dataset. Timestamped incidents,
planner decisions, and execution outcomes are not present and are not inferred.
