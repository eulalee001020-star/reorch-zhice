# P0 Textile Schedule Pack

Source: https://zenodo.org/records/4106746

MIT-licensed real production scheduling data from a textile company. The
canonical layer includes work orders, routed operations, resources, and the
published schedule. Injected incidents are always labeled synthetic.

Known boundary: published schedule assignments do not carry stable work-order
instance identifiers, so they cannot be joined to generated work orders without
inventing lineage.
