# P1 Flexible Packaging Pack

Source: https://data.mendeley.com/datasets/h66hb89k6z/1

CC BY 4.0 scheduling data containing machines, processes, routes, product types,
and orders. The repository page does not establish that all data came from a
real factory, so the manifest deliberately uses
`public_research_dataset_unverified_factory_origin`.

Process-to-machine mappings are inferred from the published machine names and
reported as an explicit transformation assumption.
