## 对外一句话

ReOrch 智策是一套部署在 ERP、MES、APS 之上的工业异常重决策操作层。当设备故障、插单、缺料、质量返工等扰动打断计划时，系统帮助计划员完成影响分析、候选方案生成、质量门校验、人工确认、受控回写和经验沉淀。

## 当前阶段

当前可以谨慎表述为：MVP 已完成，具备可运行 demo、前后端模块、样例数据、质量门、实验室 replay 证据、失败样本库和上线边界文档；P0 Reality Harness、约束标定、Replay/Shadow 验证、shadow case 采集和 Agent 成本可观测已经形成最小可运行模块，正在从受控验证走向真实客户只读数据 replay / shadow mode。

当前不应表述为：已完成客户生产部署、可无人值守自动调度、已证明所有客户 ROI、或已经替代 ERP/MES/APS。

长期可以表述为：ReOrch 以异常重决策作为进入计划系统的 wedge，未来补齐初始排程、滚动排程、全约束建模、主流系统集成、生产发布和企业级 SLA 后，可以从异常层升级为完整 AI APS / 排产操作系统。
