# ReOrch 智策在线 Demo

面向制造业异常响应的可互动决策工作台，展示设备停机、物料延期与质量返工后的受控决策闭环。

## 交互范围

- 在异常队列中切换事件，查看影响范围与事实输入。
- 对比三个满足硬约束的候选恢复方案。
- 查看数据健康、证据来源、Agent Trace 与质量门结果。
- 选择候选方案并完成人工确认。

Demo 使用合成数据，不连接生产系统，也不执行真实写回。AI 负责异常语义理解、证据解释和风险提示；排程可行性由确定性求解器与质量门验证。

## 本地运行

```bash
npm ci
npm run dev
```

验证生产构建：

```bash
npm run lint
npm test
```
